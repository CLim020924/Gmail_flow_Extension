# Gmail Flow 온라인 예약 발송 설정

이 구성은 예약할 때 Gmail 초안을 Google 계정에 먼저 만들고, Google Apps Script의 1분 주기 트리거가 예약 시간이 되면 초안을 발송합니다. 등록을 마친 뒤에는 Gmail Flow 앱과 PC가 꺼져 있어도 Google 쪽에서 처리됩니다.

## 최초 1회 설정

1. [Google Apps Script](https://script.google.com/)에서 새 프로젝트를 만듭니다.
2. 이 폴더의 `Code.gs`와 `appsscript.json` 내용을 같은 이름의 파일에 복사합니다.
3. 편집기에서 `setupOnlineScheduler` 함수를 한 번 실행하고 Gmail·Drive·Sheets·트리거 권한을 승인합니다.
4. **배포 → 새 배포 → 웹 앱**을 선택합니다.
   - 실행 사용자: **나**
   - 액세스 사용자: **모든 사용자(Anyone)**. 조직 정책으로 불가능하면 조직 내부의 익명 호출 허용 범위를 사용해야 하며, 로그인 필수 배포는 현재 앱의 연결 테스트를 통과하지 못합니다. 요청은 별도의 긴 연결 키로 보호됩니다.
5. 배포 후 `getOnlineSchedulerSetup`을 실행합니다. 실행 결과의 `webAppUrl`과 `secret`을 Gmail Flow 설정에 입력합니다.
6. Gmail Flow 설정에서 **연결 테스트**를 누릅니다. 실행 방식 선택은 없으며 연결된 뒤의 모든 새 예약은 온라인으로 등록됩니다.

웹 앱 코드를 바꾼 뒤에는 반드시 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 합니다. 연결 키가 노출된 경우 `rotateOnlineSchedulerSecret`을 실행하고 앱에 새 키를 입력합니다.

## 동작 및 제한

- 트리거가 1분 단위이므로 실제 발송은 예약 시각보다 수십 초 늦을 수 있습니다.
- Google 계정의 Gmail/Apps Script 일일 할당량과 첨부파일 제한을 따릅니다.
- 한 작업은 최대 100명, 첨부파일 합계는 18MB로 제한합니다. 인원이 더 많으면 작업을 나누어 예약합니다.
- 온라인 작업 데이터는 해당 Google 계정의 비공개 스프레드시트와 Drive 폴더에 보관하고, 완료 후 90일이 지나면 정리합니다.
- Apps Script 배포 계정과 Gmail Flow에서 선택한 발신 계정이 같아야 합니다.
- 발송 직후 서버가 중단되어 초안 상태를 확정할 수 없는 극단적인 경우에는 중복 발송보다 안전하도록 자동 재발송하지 않고 실패로 표시합니다.
