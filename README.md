# Gmail Flow Extension

사용자 정의 명단, 변수, 메일 템플릿, Gmail 초안·발송·예약·기록 기능을 제공하는 Chrome 확장 프로그램입니다.

## 현재 구현 범위

- Manifest V3 확장 프로그램 골격
- 발송 방식별 조건부 메일 작성 UI
- 명단 행과 추가 빈 초안을 합산하는 임시 저장 수량 계산
- Excel/CSV/탭 구분 표 붙여넣기와 컬럼 자동 생성
- 컬럼 이름·역할 수정
- 명단 저장·조회·불러오기·이름 변경·삭제
- 메일 템플릿 저장·조회·적용
- 발송 기록 하위 화면 데모
- `chrome.storage.local` 기반 로컬 저장

Gmail OAuth, Gmail API 실제 초안·발송, 영속 예약 작업 큐는 다음 구현 단계입니다.

## Chrome에 불러오기

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 저장소 폴더를 선택합니다.

## 개발

빌드 과정이 없는 정적 Manifest V3 프로젝트입니다. 파일을 수정한 뒤 확장 프로그램 관리 화면에서 새로고침하면 됩니다.
