# 사용자 요청 및 기능 변화 기록

이 문서는 CMOE Workspace와 Gmail Flow의 사용자 요청, 해석, 실제 기능 변화, 검증 결과를 한 흐름으로 연결한다. Git 커밋은 코드의 변경점을 보존하고, 이 문서는 **왜 바뀌었는지와 어떤 요청에서 시작되었는지**를 보존한다.

개인정보가 포함된 명단·이메일·전화번호 예시는 원문을 복제하지 않고 데이터 형식만 기록한다. OAuth 비밀키, 토큰, 계정 비밀번호도 기록하지 않는다.

## 기록 규칙

앞으로 기능 요청을 처리할 때 다음을 함께 갱신한다.

1. 요청마다 `REQ-연월일-번호`를 부여한다.
2. 사용자의 요청 핵심 문장을 가능한 그대로 남긴다.
3. 기존 동작, 변경 이유, 최종 동작을 연결한다.
4. 구현 파일과 검증 방법을 적는다.
5. 완료 커밋 해시를 적고, 미완료이면 `설계`, `진행 중`, `보류`로 표시한다.
6. 기존 기능을 다시 바꾸면 이전 요청 ID를 `이전 단계`에 연결한다.
