CMOE Workspace 1.15.2

- CMOE Workspace는 설치형만 배포합니다. 휴대형 빌드와 배포 경로를 제거했습니다.
- 새 버전은 기존 저장 데이터를 열기 전에 `%APPDATA%/CMOE Workspace Backups`에 복구용 스냅샷을 만듭니다.
- 백업에는 프로젝트·설정, 보호된 계정 자료, 사용자 확장, 문서 템플릿, Gmail Flow 명단·메일 양식·예약 기록이 포함됩니다.
- 자동 업데이트는 종료 직전 데이터를 다시 백업하며, 백업에 실패하면 설치기를 실행하지 않습니다.
- 앱을 제거하더라도 사용자 데이터는 자동으로 삭제하지 않습니다.
- 업데이트 다운로드 취소, 공식 릴리스 경로·크기·SHA-256, 설치 후 파일 버전 검증을 유지합니다.

주의: Windows 코드 서명 인증서가 아직 적용되지 않아 실행 시 Windows 경고가 나타날 수 있습니다.
