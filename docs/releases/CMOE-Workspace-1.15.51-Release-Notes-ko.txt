CMOE Workspace 1.15.51 변경 안내

참여 조건으로 결과 대상 선택
- A/B에서 이름·전화번호·메일처럼 여러 공통 열을 연결한 뒤, B 참여상태가 `미참여`인 사람처럼 결과에 넣을 조건을 추가할 수 있습니다.
- 같음, 포함, 같지 않음, 포함하지 않음, 비어 있음, 값이 있음 조건을 지원합니다.
- 조건이 여러 개이면 모두 만족하는 사람만 `일괄 발송 명단`에 포함하며, 전체 연결 인원과 조건 통과 인원을 구분해 보여줍니다.

A/B 공통 열 통합과 자동 배열
- 위에서 비교한 이름·전화번호·메일 등의 A/B 열을 결과에서 각각 한 열로 통합할 수 있습니다.
- `공통 열 통합 → A 나머지 → B 나머지` 또는 반대 순서로 결과 열을 한 번에 구성할 수 있습니다.
- 자동 구성 뒤에도 열을 제외하거나 위·아래 버튼으로 순서를 다시 조정할 수 있습니다.
- 통합 열은 사용자가 선택한 A/B 우선순위의 값을 사용하고, 우선값이 비어 있으면 반대쪽 값을 사용합니다.

기존 기능 보존
- 서로 다른 파일과 같은 파일의 다른 시트, 최대 12개 비교 열, 전화번호·이메일 정규화, 중복·미매칭 검토 시트, 선택형 그룹 시트를 그대로 지원합니다.
- 원본 Excel 파일은 변경하지 않고 새 XLSX 결과 파일을 만듭니다.
