CMOE Workspace 1.15.1

- 1.14.8에서 복구한 UI와 문서·명단·일정·Forms·Gmail Flow 기능을 그대로 유지했습니다.
- 업데이트 다운로드를 취소할 수 있고 부분 파일은 자동으로 정리됩니다.
- 업데이트 정보의 버전·제품·플랫폼·파일 경로·크기·SHA-256을 확인합니다.
- 종료할 앱의 PID와 실행 경로를 확인한 뒤 설치하고, 설치된 EXE의 파일 버전이 올바를 때만 한 번 재실행합니다.
- 동일 버전 재설치와 다운그레이드를 차단하고, 이전 버전이면 업데이트·제거·닫기를 선택할 수 있습니다.
- 바탕화면·시작 메뉴의 같은 프로그램 바로가기와 구 명칭 바로가기가 중복되지 않도록 정리합니다.
- 앱을 두 번 실행하면 새 프로세스를 남기지 않고 기존 창을 복원해 활성화합니다.

주의: Windows 코드 서명 인증서가 아직 적용되지 않아 실행 시 Windows 경고가 나타날 수 있습니다.
