CMOE Workspace 1.3.0 변경 안내

- 예약 발송 실행 위치 선택을 없앴습니다. 모든 새 예약은 Apps Script 온라인 예약으로 등록됩니다.
- 예약 등록 시 연결한 Gmail 계정의 초안을 만들고, 예약 시각에는 Apps Script 시간 트리거가 발송합니다.
- 이전 버전에서 로컬 실행을 선택했더라도 새 예약은 온라인 설정으로 자동 전환됩니다. 이미 등록된 로컬 작업 기록은 삭제하지 않습니다.
- 최초 한 번 Apps Script 주소와 연결 키를 확인해야 하며, Apps Script 배포 계정과 Gmail 발신 계정이 다르면 등록을 막습니다.
- 환경 설정에 새 버전 확인과 검증된 업데이트 설치 기능을 추가했습니다.
- 설치 파일은 기존 버전이 낮을 때 업데이트·제거·닫기를 제공하고, 동일하거나 더 최신이면 제거·닫기만 제공합니다.
- 앱·설치기 식별자와 사용자 데이터 위치를 유지하며 제거 시 사용자 데이터를 자동 삭제하지 않습니다.

검증: Gmail Flow와 Workspace 전체 자동 테스트, 온라인 단일 예약 마이그레이션, 업데이트 정보 검증, 빌드 사전검사와 Electron smoke.

실제 Google 계정의 Apps Script 최초 배포와 실메일 도달 발송은 각 사용자 계정에서 확인해야 합니다.
