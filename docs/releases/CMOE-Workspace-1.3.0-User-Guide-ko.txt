CMOE Workspace 1.3.0 사용 안내

예약 발송

1. Gmail Flow에서 사용할 Gmail 계정으로 로그인합니다.
2. 최초 한 번 Online-Scheduler-Setup.zip 안내에 따라 같은 Google 계정에 Apps Script를 배포합니다.
3. 설정에서 웹 앱 주소와 연결 키를 입력하고 연결 테스트를 완료합니다.
4. 메일 작성에서 예약 날짜와 시각을 정하고 예약 발송을 누릅니다.
5. 앱이 해당 Gmail 계정의 초안을 만들고 온라인 작업으로 등록합니다. 등록 완료 후에는 앱과 PC를 꺼도 됩니다.

실행 위치 선택은 없습니다. Gmail 로그인 권한만으로 앱이 사용자 계정에 Apps Script 프로젝트와 시간 트리거를 몰래 만들지는 않습니다. 최초 배포는 사용자가 Google 화면에서 권한을 확인해야 하며 이후 예약은 자동으로 온라인 방식을 사용합니다.

업데이트

- 설치형: 환경 설정에서 새 버전을 확인합니다. 공식 설치 파일의 크기와 SHA-256 검증 후 작업을 저장하고 앱을 종료하여 같은 위치에 설치한 뒤 한 번 다시 엽니다.
- 휴대형: 새 버전이 있으면 Cresero 다운로드 페이지에서 새 휴대형 파일을 받습니다.
- 동일 버전 재설치와 다운그레이드는 설치 화면에서 차단합니다. 제거해도 사용자 프로젝트와 로그인 데이터는 자동 삭제하지 않습니다.

Apps Script 배포 계정과 Gmail 발신 계정은 같아야 합니다. 한 온라인 작업은 최대 100명, 첨부파일 합계는 18MB이며 Google 계정 할당량을 따릅니다. 개발자 코드 서명이 없는 설치 파일이면 Windows가 경고를 표시할 수 있습니다.
