CMOE Workspace 1.2.0 사용 안내

1. 설치
- 권장: CMOE-Workspace-Setup-1.2.0-Windows.exe를 실행합니다.
- 설치 없이 사용하려면 CMOE-Workspace-1.2.0-Windows.exe를 실행합니다.
- 개발자 코드 서명이 없는 파일이므로 Windows SmartScreen 안내가 표시될 수 있습니다. Cresero 다운로드 페이지의 크기와 SHA-256을 확인하세요.

2. Google 계정 연결
- CMOE Workspace에서 Gmail Flow를 열고 오른쪽 위 설정을 선택합니다.
- Google 계정 연결을 누르고 Gmail 권한을 승인합니다.
- Apps Script 온라인 예약 발송을 사용할 때는 Apps Script를 배포한 계정과 같은 Gmail 계정을 연결합니다.

3. 명단과 메일
- 명단에서 컬럼과 행을 만들거나 Excel/CSV/표 데이터를 붙여넣습니다.
- 이메일로 사용할 컬럼을 지정하고 메일 작성에서 제목·본문·첨부파일을 입력합니다.
- {컬럼명}을 입력하면 각 대상의 값으로 바뀝니다.
- 발송 전 대상별 받는 사람·제목·본문을 최종 확인합니다.

4. 예약 발송
- 이 PC에서 실행: 발송 시간까지 PC와 앱을 켜두어야 합니다.
- 온라인 실행: Online-Scheduler-Setup.zip의 안내대로 Google Apps Script를 최초 한 번 배포합니다. 웹 앱 주소와 연결 키를 설정에 입력하고 연결 테스트를 통과하면, 예약 등록 후 PC를 꺼도 Google 쪽에서 발송합니다.
- 온라인 트리거는 1분 단위이므로 예약 시각보다 수십 초 늦을 수 있습니다.
- 한 온라인 작업은 최대 100명, 첨부파일 합계는 18MB입니다. Google 계정의 Gmail/Apps Script 할당량을 따릅니다.

5. 저장 자료
- 기본값은 이 PC에만 저장입니다.
- Google Drive 동기화를 선택하면 명단·구조·메일 템플릿·작성 설정을 같은 계정의 다른 PC에서 불러올 수 있습니다.
- 로그인 토큰, 발송 작업, 첨부파일과 Apps Script 연결 키는 Drive 동기화에 포함하지 않습니다.

6. 주의
- 실제 발송 전 소수의 테스트 주소로 먼저 확인하세요.
- 이미 발송된 메일은 수정하거나 회수할 수 없습니다.
- 온라인 예약 작업을 취소하면 아직 발송하지 않은 Gmail 초안을 삭제합니다.
- 계정, 받는 사람, 예약 시간과 첨부파일은 사용자가 최종 확인해야 합니다.
