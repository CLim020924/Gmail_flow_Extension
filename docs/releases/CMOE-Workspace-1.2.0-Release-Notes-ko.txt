CMOE Workspace 1.2.0 변경 안내

- Gmail Flow 0.6.0을 포함합니다.
- Google Apps Script 온라인 예약 발송을 추가했습니다.
- 기존 로컬 예약과 온라인 예약을 설정에서 선택합니다.
- 온라인 예약은 등록 후 PC와 앱이 꺼져도 Apps Script 트리거가 처리합니다.
- 온라인 작업의 상태 동기화와 취소를 지원합니다.
- 예약 작업의 실행 위치를 작업 큐와 발송 기록에 표시합니다.
- 온라인 작업은 최대 3회 재시도하며 불확실한 상태에서는 중복 발송 방지를 우선합니다.
- Windows 실행 파일과 설치 관리자에 Gmail Flow 메일 흐름 아이콘을 적용했습니다.
- 기존 명단, Excel식 편집, 변수 자동완성, 다중 첨부파일, 초안·즉시 발송, Google Drive 선택형 동기화와 Workspace 기능을 유지합니다.

확인된 검사:
- Gmail Flow 전체 자동 테스트
- Apps Script 서버 등록·중복 방지·시간 도달 발송·취소 모의 테스트
- CMOE Workspace 전체 자동 테스트와 빌드 사전검사
- Electron 개발본 및 패키징 실행본 smoke
- 실행 파일 제품명·버전·아이콘·SHA-256 확인

실제 Google 계정의 Apps Script 웹 앱 배포와 실메일 시간 도달 발송은 각 사용자가 자신의 계정에서 최초 설정 후 확인해야 합니다.
