CMOE Workspace 1.15.48 변경 안내

1. 대량 메일 안전 발송
- 한 Gmail 계정에서 실제 메일을 5초에 한 통씩 전송합니다.
- Gmail API messages.send 기준 분당 약 1,200 quota units만 사용해 분당 6,000단위 안에서 다른 Gmail 작업 여유를 남깁니다.
- 작업 큐에 다음 발송까지의 안전 간격 대기를 표시합니다.

2. 사용량 제한 자동 대기
- Gmail API 403 rate limit, 429, 5xx와 일시 네트워크 오류만 자동 재시도합니다.
- Google이 Retry-After를 제공하면 그 시간을 우선 따르고, 없으면 최대 8회 지수 백오프합니다.
- 영구 오류는 반복 전송하지 않습니다.

3. 실패 대상만 다시 보내기
- 발송 기록에서 실패한 사람이 있을 때 `실패 대상 다시 보내기`가 나타납니다.
- 이미 성공한 사람은 제외하고 실패 대상만 받는 사람·제목·본문을 다시 확인한 뒤 새 작업으로 등록합니다.

4. 온라인 예약 발송
- 최신 Apps Script는 5초 간격으로 한 트리거 실행당 작업별 최대 12명을 보내고 남은 대상은 다음 1분 트리거에서 이어갑니다.
- 이전 온라인 예약 스크립트는 새 예약 전에 갱신해야 합니다. Online-Scheduler-Setup-1.15.48.zip의 README 순서대로 기존 Code.gs를 교체하고 새 버전으로 재배포한 뒤 앱에서 연결 테스트를 다시 실행하세요.

주의
- 속도 조절은 순간 발송량과 일시적인 API 제한 위험을 줄이지만 잘못된 주소, 수신 회사 정책, 스팸 신고, SPF/DKIM/DMARC 또는 Gmail 일일 발송 한도까지 없애지는 않습니다.
- 기존 프로젝트·명단·템플릿·계정 자료와 발송 기록은 업데이트 시 보존됩니다.
- 설치 파일은 공인 Windows 코드 서명이 없는 상태입니다.
