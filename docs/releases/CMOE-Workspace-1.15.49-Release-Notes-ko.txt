CMOE Workspace 1.15.49 변경 안내

메일별 전송 간격 선택
- 즉시 발송과 예약 발송의 최종 확인창에서 2~60초 범위로 메일 한 통당 간격을 직접 지정할 수 있습니다.
- 기본값은 기존 안전값인 5초입니다.
- 같은 회사 주소에 집중 발송할 때는 8~10초를 권장합니다.
- 실패 대상만 다시 보내는 작업에서도 새 간격을 선택할 수 있습니다.

Gmail 실제 발송 기록 확인
- Gmail API 발송 요청이 성공한 것만으로 완료하지 않습니다.
- Gmail 보낸편지함에서 해당 메시지 ID와 SENT 기록을 다시 확인한 뒤에만 `발송 확인`으로 표시합니다.
- 기록 확인이 늦을 때는 메일을 다시 보내지 않고 조회만 재시도해 중복 발송을 방지합니다.
- Gmail이 명확히 거절한 메일은 `미발송 확인`으로 표시합니다.
- 네트워크 시간 초과나 Gmail 서버 오류처럼 요청 결과를 단정할 수 없는 메일은 `결과 불명`으로 분리하고 자동 재전송에서 제외합니다.
- `미발송 확인 대상 다시 보내기`에는 안 보내진 것이 확인된 대상만 포함됩니다.

온라인 예약 발송 스크립트 갱신 필요
- 예약 발송에서 선택 간격과 보낸편지함 확인을 사용하려면 설치 파일에 포함된 online-scheduler-setup의 Code.gs로 Apps Script를 갱신하고 새 버전으로 재배포해야 합니다.
- 갱신 후 Gmail Flow 설정에서 온라인 예약 발송 연결 테스트를 다시 실행하세요.
